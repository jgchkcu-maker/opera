# Opera-print redesign prototype

Полный статический редизайн публичного сайта Opera-print на основе текущего содержания operaprint.ru.

## Что внутри

- `index.html` — главная.
- `services.html` — полный каталог продукции с поиском и фильтрами.
- 23 карточки/позиции каталога и отдельные статические страницы продуктовых направлений.
- `builder.html` — интерактивный конструктор заказа.
- `capabilities.html` — возможности печати и оборудование.
- `postpress.html` — 15 видов постпечатной обработки.
- `prepress.html` — допечатная подготовка.
- `requirements.html` — технические требования в читаемом виде.
- `delivery.html` — оплата и доставка.
- `contacts.html` — контакты и менеджеры.
- `assets/` — общие CSS/JS и каталог услуг.

## Запуск

Можно открыть `index.html` напрямую. Для локального веб-сервера:

```bash
python -m http.server 8000
```

и открыть `http://localhost:8000/`.

## Важно

Это frontend-прототип. Конструктор формирует техническое задание, но сам не отправляет его на почту/CRM — backend-интеграцию нужно подключить отдельно. Фотографии и логотипы клиентов используются как внешние ссылки на текущий сайт Opera-print; для боевого размещения их лучше перенести в собственное хранилище проекта.
